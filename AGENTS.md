# SmartRide implementation contract
Use C++17, OpenStreetMap public data, std::thread, free tools, and no GUI.
Build milestones in order; verify each before continuing. Work autonomously;
ask only for genuine blockers, credentials, spending, or required permissions.
Keep code modular and understandable. Never invent measurements. Record any
blocked/unverified requirement and save progress before stopping.

Requirements and verification checklist live in PLAN.md; update PROGRESS.md
as work proceeds. Preserve source attribution and reproduction commands.
Do not mix sanitizer measurements with optimized performance results.
